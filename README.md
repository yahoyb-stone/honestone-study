# 어니스톤 스터디 — 인증 전문가 스터디

기업인증(벤처기업확인·이노비즈·기업부설연구소·ISO)이 정책자금·입찰 가점·세제
혜택으로 이어지는 구조를, 컨설팅에 맡기기 전에 대표가 먼저 아는 것을 목표로 한
전 8회 스터디의 사전 신청 사이트입니다.

## 내용을 고치는 곳

거의 모든 문구가 **`src/config/study.ts` 한 파일**에 있습니다. 커리큘럼 8회차,
대상, 진행 방식, FAQ, 리더 소개, 그리고 아직 정해지지 않은 값(일정·회비·정원)이
모두 여기 있습니다.

정해지는 대로 아래를 채우면 화면과 공유 이미지(OG)가 함께 바뀝니다.

| 값 | 지금 | 정해지면 |
| --- | --- | --- |
| `study.schedule` | "1기 멤버가 모이면 …" | `"매주 화요일 저녁 7:30 · 2시간"` |
| `study.fee` | "추후 안내" | `"회당 3만원"` 등 |
| `study.capacity` | "소수 정원" | `"10명 내외"` 등 |
| `study.place` | "부천·강서 일대 (확정 후 안내)" | 실제 주소 |

사이트 이름을 바꾸고 싶으면 같은 파일의 `site.name` · `site.brand` 두 줄만
고치면 됩니다.

## 신청은 어디에 쌓이나

신청은 `/api/apply` 를 거쳐 Supabase 의 `submit_visitor_request` RPC 로
저장됩니다. **어니스톤이 이미 쓰고 있는 Supabase 프로젝트의 값을 환경변수에
넣으면**, 여기서 접수한 분도 기존 관리자 화면의 명단·문자 도구에 그대로
나타납니다. 분류는 `studyAssignLabel`("인증 전문가 스터디 1기")로 갈립니다.

새 신청이 들어오면 알림 메일이 갑니다(SMTP 값을 넣은 경우에만). 메일 설정이
없어도 접수 자체는 정상 동작합니다.

## 환경변수

`.env.example` 을 보고 채우면 됩니다. 최소한 아래 둘이 있어야 신청이 저장됩니다.

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

도메인을 연결한 뒤에는 `NEXT_PUBLIC_SITE_URL` 을 넣어 주세요. 넣지 않으면
Vercel 이 알려주는 배포 주소를 씁니다.

## 개발

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 배포 전 확인

```
